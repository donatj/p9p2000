# PHP Plan 9 9P2000 

This is a toy implementation of Plan 9's 9P2000 as a PHP stream wrapper alowing things like

>  file_get_contents('9p://localhost:564/path/to/file');

It's very buggy and only works with certain 9p2000 servers.
